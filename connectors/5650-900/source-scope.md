# Source Scope for 5650 / 900

## Purpose

This document defines the source boundary for spreadsheet-governed SAD administrative workflows associated with `5650` / `900` at the connector planning layer.

## Governance

This connector is governed by:
- `sad-moron-framework`
- declared source protocol
- temporal boundary protocol
- evidence classification protocol
- connector compliance protocol

## Scope Statement

At this stage, `5650` / `900` is treated as a governed spreadsheet workflow specification for SAD administrative processes such as Res. 5650, MAD, and related workflow families pending formal source declaration.

This pack assumes a Google Sheets-oriented administrative workflow surface for declared operational records, with any later bounded implementation belonging in `sad-moron-appscript`.

This pack must not be interpreted as:
- a COBOL source connector
- a direct legacy system connector
- a direct provincial system connector
- a license for unrestricted spreadsheet discovery

The exact declared sheets, tabs, ranges, and process boundaries must still be formally confirmed.

## Required Source Conditions

Any future implementation path requires:
1. process family identification
2. declared Google Sheets source confirmation
3. institutional purpose
4. temporal reconstruction window
5. required fields by process
6. excluded fields
7. audit/evidence expectations
8. known data limitations
9. reusable workflow boundary for later Apps Script implementation

## Allowed Institutional Use

Allowed use is limited to:
- bounded institutional review
- source contract planning
- evidence-aware connector scoping
- later audit-compatible interpretation
- spreadsheet workflow classification for SAD administrative processes

## Excluded Use

Excluded use includes:
- unrestricted ingestion
- exploratory scraping
- speculative data capture
- use beyond declared institutional purpose
- silent widening of source boundary
- reclassifying this pack as COBOL or legacy/provincial system integration without declared evidence

## Declared-Source Requirement

This connector cannot become governed implementation until the relevant spreadsheet workflows and their declared Google Sheets sources are formally described in the declared sources catalog.

## Summary

The source boundary for `5650` / `900` is a spreadsheet-governed SAD workflow boundary pending declared Google Sheets confirmation, not a COBOL or direct legacy-system boundary.
