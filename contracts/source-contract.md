# Source Contract

## Purpose

This contract defines the minimum source contract a connector must reference.

## Required Source Elements

Every source contract must define:
- source name
- institutional origin
- document or record class
- intended governance use
- temporal relevance
- known limitations
- boundary note

## Source Constraints

A source contract must ensure:
- the source is institutionally intelligible
- the source boundary is explicit
- temporal interpretation is possible
- later audit reconstruction is not blocked by ambiguity

## Exclusions

This contract does not define authentication, storage, or extraction mechanics.

## Summary

The source contract is the minimum governance anchor for any future connector behavior.
